# What to bring to your first cost estimate

A plot size and a bedroom count can start the conversation. A few more details make the estimate much easier to use.

## Start with the land

Bring the plot dimensions, its location and any photographs of access from the street. Mention slopes or existing structures. A house on a clear, level plot and one that needs retaining walls have different starting costs.

## Describe the home you need

Write down who will live there, which rooms need privacy and whether you intend to build in stages. If you have drawings, bring the latest dated set so everyone prices the same scheme.

## Define what the price includes

List the items you expect on handover. Boundary walls, a water tank, fitted wardrobes and external paving can sit outside a house quotation. Ask for each inclusion and allowance in writing before comparing totals.
